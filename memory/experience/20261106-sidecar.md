# 2026-11-06 · sidecar：GUI 与核心的 HTTP 契约

## 设计与实现
- 纯 stdlib：`ThreadingHTTPServer` + `BaseHTTPRequestHandler`，无第三方依赖。
- `POST /rpc {method, params}` → `{ok, result}`；`GET /events?job&since` → SSE。
- 鉴权用共享 token（header `X-Sidecar-Token`），端口随机 + 写 port-file，避免端口冲突与局域网暴露。
- Job 模型：事件历史 + `threading.Event` 取消 + done 标记；pipeline 通过 `should_stop` 在 depot 边界停止。

## 坑
- `server.shutdown()` 不释放 socket，测试里必须再 `server_close()`，否则一堆 ResourceWarning。
- 进度回调要设计成 job.push(event) 而不是 print，否则 GUI 拿不到结构化数据。

## 复用
`python -m steam_research.cli sidecar --port-file out.json` 即可给任何前端（Tauri/浏览器/脚本）用。
