# 2026-11-06 · MVP 端到端：sidecar 托管 Web UI

## 结构
- `src/py/steam_research/webui/index.html` + `app.js`，由 sidecar 在 `/`、`/app.js`、`/session` 托管。
- 前端只用 fetch + EventSource；token 从 `/session` 取（仅 loopback 可达）。

## 实测（480）
- coverage：1 depot，key 有，manifest 200，1.8 MB。
- restore：`[done] ok=true depots=1/1 bytes=1906055`；落盘 9 文件（含 state）。
- 截图：`tests/reports/mvp-ui-done.png`。

## 坑
- 改 sidecar 代码后必须**重启进程**，否则 UI 跑的是旧逻辑（遇到 `files=undefined` 就是这个原因）。
- PowerShell 写 JSON 时单元素数组会被压成对象，缓存解析失败会静默回退到 steamcmd（很慢）——用 Python 写或显式 `[...]`。
- EventSource 不能带 header，token 必须支持 query 参数。
