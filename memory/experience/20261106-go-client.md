## 两个致命 bug（值得记住）
1. **组装必须按 Chunk.Offset 写入**：顺序拼接在带空洞的清单上会让 sha1 全错；正确做法 `WriteAt(data, offset)` + `Truncate(file.Size)`。症状极具误导性：per-chunk sha1 全过、per-file sha1 全错。
2. **VZip footer 长度是 uint32**：读成 uint64 会越界 panic；示例 chunk 恰好是 VZstd，所以单 chunk 测试发现不了，必须用真实 depot 全量跑。

## 其他要点
- 覆盖判定与 Python 一致：key && (镜像 200 || 索引有回退)。
- CDN 需要 `User-Agent: Valve/Steam HTTP Client 1.0`，且要按 3 个主机轮询重试。

## 教训
跨语言重写时，「chunk 正确」≠「文件正确」：结算单位要提到文件级，最好整 app 对拍。
