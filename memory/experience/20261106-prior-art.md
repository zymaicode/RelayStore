# 2026-11-06 · 先例调研：别人早就做成了，而且和我们同构

## 关键发现
- DepotDownloader（3.5k★）、Onekey（1.4k★）、SFF/SteaMidra（2.0k★）、SteamAutoCracks/ManifestHub（2.25k★）都是成熟实现。
- 架构一律是：manifest 缓存 + key.vdf + lua + DepotDownloader/模拟器 —— 和我们搭的一模一样。
- **没有任何项目破解 depot key**；key 全部来自持有者导出（config.vdf / key.vdf）。
- Denuvo 的公开进展只在 hypervisor 层（hypervisor-crack-audit），不是文件层能解决的事。

## 实测（steamtools.games，免注册公共 API）
POST /api/generate {"appId":"4115450"} → not_in_db。
第三方独立确认了我们的结论：影之刃零目前无人分享。该接口对已收录游戏返回 lua + key.vdf。

## 对项目的意义
1. 我们的定位应强调「逐文件校验 + 可复现」，这是生态里普遍弱的一环。
2. 能借力就借力：steamtools.games 的 key.vdf 可扩充语料；Hubcap 补按需 manifest。
3. 判断新作是否进生态，一条 curl 即可，可当雷达探针。
