# 分发源候选（《影之刃零》138.65 GiB 包 / 通用大文件分发）

> 目标：把 138.65 GiB 的包分发出去，**接收方不需要迅雷账号、不需要会员、不需要 cookie**。
> 背景：迅雷分享链接在非转存状态下被限速到 0.04 MB/s（见 ARD D-031/D-032），因此只能作为**自用搬迁源**，不能作为分发源。

## 2. 搬家流水线（本地只需 4 GB 临时空间）

```text
循环 35 次：
  ① 迅雷 drive 链接下载 1 卷（4 GB，10 MB/s，≈7 分钟）
  ② 校验 sha256（与清单比对）
  ③ 上传到对象存储 / 网盘（rclone 或直传 API）
  ④ 删除本地该卷
  ⑤ 记录（卷名 / sha256 / 云端 URL）
```

- 耗时估算：下载 ≈ 4 h；上传取决于上行带宽（30 Mbps ≈ 10 h / 500 Mbps ≈ 40 min）。
- 完成后产物：`manifest.json`（35 卷 sha256 + 云端 URL）+ `install.ps1`（1 MB 安装器）。

## 3. 清单（`manifest.json`）实际字段

已生成私有清单 `backup/private/pbz-manifest.json`（**不入库**）：

```json
{
  "app": "Phantom Blade Zero",
  "share": { "id": "VP5jsO1sE_PNlPaDSnsdT2ibA1", "pwd": "8awk" },
  "parts": [
    { "name": "PBZ.part001.exe", "size": 4294859776, "sha1": "F19DD029…", "md5": "", "sha256": "" }
  ],
  "totals": { "files": 35, "bytes": 148505917219 }
}
```

- **sha1**：来自迅雷 `hash` 字段，35/35 全部可取（整文件 SHA-1，比 RAR CRC 硬）。
- **sha256**：只有实际下载过的卷才有（目前仅 part001），下载即回填。
- 校验策略：`sha1` 全部可验；`sha256` 逐卷下载后补齐并写回清单。

## 4. 安装器侧（与分发源解耦）

```json
{
  "parts": [{ "name": "PBZ.part002.rar", "size": 4294859776, "sha256": "..." }],
  "sources": [
    { "type": "http", "base": "https://cdn.example/pbz/" },
    { "type": "xunlei", "share": "...", "pwd": "..." },
    { "type": "magnet", "uri": "magnet:?xt=..." }
  ]
}
```

安装器按 `sources` 顺序尝试，任一条可用即可；**迅雷只是其中一个可选源，不再是唯一依赖**。
